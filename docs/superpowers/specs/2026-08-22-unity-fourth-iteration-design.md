# UNITY fourth iteration UX design

Дата: 2026-08-22

## Goal

Сделать мобильное и desktop-взаимодействие UNITY спокойнее и премиальнее: убрать служебный шум, дать естественный swipe, сократить события, сделать FAQ и карту понятными с первого взгляда.

## Decisions

### FAQ

FAQ больше не использует визуально стандартные `details/summary`. Каждый вопрос станет контролируемым accordion-item с индексом `01–07`, мягкой orange-индикацией активного пункта, увеличенной hit-area и плавным раскрытием ответа. Одновременно открыт максимум один ответ. В DOM сохраняются `aria-expanded`, `aria-controls` и регион ответа.

### Map

Под iframe будет один заметный full-width CTA «Открыть в Яндекс Картах» с адресом UNITY рядом. Техническая схема не показывается в обычном потоке. При отсутствии embed URL вместо маленькой неясной ссылки показывается отдельный fallback-блок с ясным заголовком «Ориентир для входа».

### Events and reviews

Автопереход слайдов остаётся внутренним поведением, но служебные подписи «Листайте сценарии», интервал, pause/resume и «Предложить свой формат» убираются из интерфейса. Остаются только минимальные dots/arrows, а touch/pointer swipe переключает событие. Переход выполняется через один компактный motion-state без белой паузы. Отзывы используют тот же тихий паттерн: автор, дата, dots и swipe/autoplay без отдельной pause-кнопки.

### Formats

Заголовок становится «Форматы отдыха в UNITY». На mobile четыре карточки превращаются в горизонтальную snap-ленту, где край следующей карточки подсказывает продолжение. Карточки уменьшаются по высоте, но сохраняют читаемую кнопку выбора формата. Desktop остаётся четырёхколоночным.

### Header and community CTA

Мобильный burger получает аккуратный morph List/X, контрастный active-state и overlay-nav с staggered появлением ссылок. CTA community становится полноценной navy-кнопкой с VK-blue accent и заметной стрелкой.

## Acceptance criteria

- `390×844` и `320×844`: нет horizontal overflow; formats можно пролистывать пальцем; events меняются swipe и arrows.
- FAQ открывается по клику/клавиатуре, отвечает только один item, имеет `aria-expanded` и плавное состояние.
- Под live-картой видна одна большая карта-ссылка; маленькая «Показать схему» отсутствует при рабочем embed.
- В events DOM нет пользовательских надписей про интервал, pause и «Предложить свой формат».
- В community VK CTA заметнее прежней текстовой ссылки.
- `npm run test:run`, `npm run build`, `npm audit --omit=dev --audit-level=high` проходят; Browser fresh-load проверяет public URL.
