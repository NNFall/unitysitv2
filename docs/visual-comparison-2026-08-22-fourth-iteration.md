# UNITY — визуальная проверка четвертой итерации

Дата проверки: 22 августа 2026 года  
Локальный адрес: `http://127.0.0.1:4173/`  
Поверхность проверки: встроенный Browser, свежие вкладки после reload.

## Что сравнивалось

| Область | Desktop 1920×1080 | Mobile 390×844 | Mobile 320×844 |
| --- | --- | --- | --- |
| Viewport CSS | `clientWidth=1905` | `clientWidth=375` | `clientWidth=305` |
| Горизонтальный overflow | `scrollWidth=1905` | `scrollWidth=375` | `scrollWidth=305` |
| Hero | wide billiards editorial frame, CTA и ribbon в первом экране | hero и burger помещаются, изображение начинается после copy | без горизонтального среза |
| Formats | четыре равные карточки, заголовок «Форматы отдыха в UNITY» | `display:flex`, snap-rail, карточки по 320 px | rail сохраняет ширину viewport |
| Events | feature-stage 430 px, controls под карточкой | feature-stage около 545–600 px, touch-action `pan-y` | без overflow |
| Booking/map | live Yandex iframe + адрес + full-width CTA под картой | map iframe 330 px + CTA под адресом | layout сохраняет ширину |
| FAQ | premium accordion, один открытый пункт | один открытый пункт, анимированная панель и orange plus | все 7 вопросов доступны |

## Интерактивные проверки

- События автоматически переключились с `1 из 3` на `2 из 3` после 5,7 секунд.
- В DOM отсутствуют сервисные подсказки «Листайте сценарии», «каждые 5,6 сек», «Поставить автопрокрутку на паузу» и «Предложить свой формат».
- Переход между событиями оставляет stage заполненным: при смене слайда высота stage сохраняется, белого промежутка нет.
- Форматы имеют горизонтальную мобильную ленту; события и отзывы поддерживают горизонтальный pointer swipe.
- Burger открывает анимированную панель, меняет aria-label/`aria-expanded` и закрывается Escape.
- FAQ использует `aria-expanded`, `aria-controls`, `role="region"`, `aria-hidden`; одновременно открыт максимум один ответ.
- Карта содержит live iframe, понятный адрес и большую ссылку «Открыть маршрут в Яндекс Картах»; fallback «Ориентир для входа» появляется только без embed URL.

## Остаточные визуальные отличия

- Контент и изображения остаются editorial/AI-assisted материалами, поэтому crop и плотность деталей не совпадают с исходными PNG-подложками пиксель-в-пиксель.
- Browser surface ограничивает ширину отрисованного screenshot, но CSS-геометрия подтверждена по `clientWidth/scrollWidth`; признаков переполнения страницы нет.
